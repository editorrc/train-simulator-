Де ми зараз

Збудовано фундамент і ядро руху поїзда. Це ще не гра з кабіною: зараз можна їздити по синтетичному полігону, а фізика вже перевіряється тестами. Цифри ЕР9М поки оцінні й позначені в даних як неперевірені.

Що вже вміє ядро

  • Рух по графу колій, стрілки, взріз стрілки як порушення
  • Опір руху (основний, від ухилу, у кривих, при рушанні з місця)
  • Тяга з обмеженням за потужністю і зчепленням, боксування
  • Кран машиніста I–VI (спрощено), реверсор, контролер 0–4
  • Стрілку під поїздом перевести не можна
  • Детермінізм: той самий запис команд дає ту саму поїздку

Запустити локально

git clone … && cd train-simulator-
pip install -r tools/requirements.txt
make check GODOT=/шлях/до/Godot_v4.7.2   # тести, як у CI
godot --path game                          # 2D-демо в Godot
open web_preview/index.html                # ця сторінка

Тягові й гальмівні характеристики ЕР9М — заглушки для розробки. Точні значення беремо з посібників з експлуатації (див. docs/RESEARCH.md).
