# Интерфейс «Панорама»

Пользователь выбрал **C** из трёх макетов: A «Депо» с боковой навигацией,
B «Схема» со светлой формой, C «Панорама» с большим поездом.
PNG концептов находятся в игнорируемом `build/ui-concepts/`; иллюстрация не
встраивается вместо модели. Используются реальные Godot UI и процедурный ЕР9М.

- Фон `#202123`, поверхность `#292B2E`, граница `#4B4E52`, текст `#EFEFF0`,
  вторичный `#A3A6AA`, акцент `#8DCEB4`, текст основной кнопки `#10231E`.
- Шаг отступов 8 px; поля 48 px; внешние поля 64 px при 1920×1080.
- Заголовок 64 px, раздел 32 px, основной текст 20 px, подпись 16 px.
- Верх: маленькое **ARTEM** над основным **Train Emulator** и «Огляд / Рейс / Поїзд / Налаштування / Керування».
- Центр: крупный заголовок, выбранный маршрут и перспективная модель 4/6/8/10 вагонов.
- По уточнению пользователя «Почати поїздку →» — активная мятная кнопка справа от
  заголовка под навигацией. Низ: сценарий, сегменты 4/6/8/10, шесть образцов окраски.
  **По уточнению пользователя нижние подсказки клавиш убраны.**
- Активная вкладка подчёркнута; hover/pressed/focus различимы; Tab/Enter в меню.
- В рейсе та же тема, видимые кнопки и пауза с продолжением. Пульт сохраняет
  вид технического оборудования, без декоративных неработающих органов.
- Названия станций — на объёмных вывесках у платформ, без висящего текста.

## Управление

Физические клавиши не зависят от языка раскладки. Command на macOS — ⌘,
Option — ⌥; Ctrl на Windows/Linux. Основные функции без F-ряда/цифрового блока.
Стрелки управляют позициями контроллера и крана; одно нажатие — одна позиция,
удержание сигнала — один непрерывный сигнал. Справка и переназначение находятся
в разделе «Керування». Общая таблица используется обработчиком и подписями.
Конфликт показывается до сохранения; Esc остаётся выходом из диалога.

## Приёмка

Сверить кадры с C: верхняя навигация, иерархия заголовков, большой предпросмотр,
единая нижняя полоса, мятная кнопка сверху; нижние подсказки отсутствуют.
Модель отличается от иллюстрации: показывается настоящий процедурный ЕР9М.
Проверить все разделы, сохранение выбора, 1280×800 и 1600×1000, пуск/паузу/
продолжение, клавиши и отсутствие команд из диалогов. Проверка нативным Godot,
поскольку браузерная страница не является интерфейсом игры.

## Сверка с эталоном C

| Опора макета | Реализация / уточнение пользователя |
|---|---|
| Горизонтальная навигация с подчёркиванием | Пять рабочих разделов; активная вкладка подчёркнута |
| Крупный заголовок над поездом | «До рейсу», маршрут/серия/число вагонов ниже |
| Большой поезд, передняя кабина слева | Перспективная линза со смещением оптической оси; полное выбранное формирование |
| Сплошная нижняя полоса | Ограниченный по ширине рейс, сегменты 4/6/8/10, шесть цветовых образцов |
| Мятный акцент | Основное действие, выбранные сегменты и рамки окраски |
| Название слева сверху | По последнему уточнению: маленькое ARTEM над Train Emulator |
| Подсказки снизу / запуск внизу | По запросу убраны; запуск перенесён вправо под навигацией |

Отличие, которое остаётся: процедурная модель и материалы уступают детализированному
поезду на концепте. Число вагонов, цвет и камера настоящие; концепт не используется
картинкой вместо работающей сцены. Точное совпадение качества модели не заявляется.
Финальные кадры QA находятся в build/ui-validation, исходные варианты в ui-concepts.

Последнее уточнение: фон нейтральный графитовый во всех UI/3D-видах; e-Ukraine
и e-UkraineHead (CC BY 4.0) загружаются по закреплённому SHA256. Знак ARTEM
собственный векторный, железнодорожный мотив. Точное качество модели остаётся открытым.
