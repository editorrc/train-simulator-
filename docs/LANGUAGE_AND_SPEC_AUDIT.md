# Аудит украинских текстов и ТТХ

Проверено для ARTEM 0.3.4: меню, настройки, справка клавиш, 15 органов/7 ламп
cab.json, процедура запуска, 20 названий кольца, названия вагонов/окрасок,
единицы и происхождение характеристик. Это редакционная проверка и аудит
источников; она не означает, что все физические параметры подтверждены.

## Терминология и исправления

| В интерфейсе | Основание/изменение |
|---|---|
| поїзд, електропоїзд, поїздка | Единый технический термин из GLOSSARY и ПТЕ; «потяг» не ошибка украинского языка, но не смешивается в этой UI |
| Забарвлення | Вместо «Окрас»; названия согласованы в среднем роде |
| Кола керування, Струмоприймач, Допом. компр. | Развёрнуты неоднозначные сокращения тумблеров |
| Увімкнення / Вимкнення ГВ | Согласованы подписи двух разных кнопок |
| Скидання захисту | Вместо неоднозначного «Поверн. РП», где РП также означает рукоятку пильності |
| ТЕД | Исправлена лампа «ТД»: тяговий електродвигун |
| Уперед / Назад | Единообразные подписи реверсора; разные команды направления вместо циклического переключения |
| ГР / ГМ, ГЦ, КМ, кВ, кгс/см² | Украинские сокращения в приборке; внутри модели остаются СИ |

Основной нормативный источник терминов:
https://zakon.rada.gov.ua/laws/show/z0050-97 — запрос доступен, но полученный
HTTP 200 оказался служебной HTML-страницей без текста ПТЕ. Полный нормативный
аудит процедур/шкал пока не закрыт; это явно отличается от исправления подписей.

## Что фактически задано в ТТХ

| Длина вагона | 21,5 м для всех типов | Оценка, verified:false; геометрия не заводская |
| Масса головного / моторного / причіпного | 48 / 66 / 40 т | Оценки, verified:false |
| Места головного / моторного / причіпного | 88 / 110 / 110 | Оценки, verified:false |

| Мощность моторного вагона | 800 кВт | Оценка, verified:false |
| База тележек / осей / диаметр колеса | 15 / 2,6 / 1,05 м | Оценки визуальной модели |

## Окраски и лицензии референсов

Три первоначальные схемы художественные. Дополнительно просмотрены фотографии:

- [ЕР9М-522](https://commons.wikimedia.org/wiki/File:ER9M-522.jpg): светлый кузов,
  жёлтые двери/полосы, красный лоб, тёмная крыша.
- [ЕР9М-537](https://commons.wikimedia.org/wiki/File:ER9M-537-Tsibuleve-Fundukleevka.jpg):
  светлый верх, голубой низ и двери.
- [ER9M-390](https://commons.wikimedia.org/wiki/File:ER9M_multiple_unit_in_Vilnius.JPG):
  красный верх и серебристый низ, литовская схема, не выдаётся за украинскую.
