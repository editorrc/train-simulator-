Демка 0.3.3 исправляет непрерывный тифон/свисток и звук качения: границы петель теперь заданы в звуковых отсчётах, записи импортируются как PCM16. Стыковой PCM-микшер оптимизирован без изменения моментов ударов осей.

Физика учитывает уклон и сопротивление кривой по полной длине каждого вагона, постепенно при въезде на новый профиль. Жёсткие детали объединены, колёсные пары инстанцируются и получают детализацию по размеру на экране. Добавлены боковые окна кабины, поручни и складывающийся токоприёмник.

Исправлено фактическое разрешение 3D: теперь оно соответствует изображению окна, включая HiDPI. Окно стартует развёрнутым, ручной размер сохраняется. Сглаживание выбирается в F3. Первый кадр с камерой у путей скрыт. F8 возвращает ракурс со стороны платформы; в 3D есть встречный демонстрационный путь и вторая наружная платформа.

Второй путь пока не маршрутизируется; модели и станции остаются иллюстративными. Пользователь подтвердил нативный запуск предыдущей 0.3.2 на Windows/macOS. Новая версия проверяется в Linux и структурно перед выдачей; hosted CI заблокирован биллингом. macOS DMG universal, ad-hoc подпись без Apple Developer ID/нотариализации.
