# Настольная демка 0.3.3

Скачать: [Windows ZIP с готовым EXE](https://raw.githubusercontent.com/editorrc/train-simulator-/360800b17bfdc6da0e2208298388d89bda39f253/TrainSimulator-Windows.zip) · [macOS universal DMG](https://raw.githubusercontent.com/editorrc/train-simulator-/360800b17bfdc6da0e2208298388d89bda39f253/TrainSimulator-macOS-universal.dmg).
Обе HTTPS-загрузки повторно скачаны и проверены по SHA256. Подробности: [BUILD_VALIDATION.md](BUILD_VALIDATION.md).

Windows: скачать TrainSimulator-Windows.zip, распаковать и запустить TrainSimulator.exe.
EXE находится внутри ZIP вместе с лицензиями. Godot, Python и браузер не нужны.

macOS: скачать TrainSimulator-macOS-universal.dmg, открыть и перетащить TrainSimulator.app
в «Программы». Внутри универсальный исполняемый файл Intel + Apple Silicon. Сборка имеет
локальную ad-hoc подпись; Apple Developer ID и нотариализации нет. Если macOS блокирует
первый запуск, используйте «Системные настройки → Конфиденциальность и безопасность →
Всё равно открыть» именно для этого приложения. Отключать защиту системы не требуется.

В меню: состав ЕР9М на 4/6/10 вагонов, три окраса, готовый поезд или холодный запуск.
Киевское кольцо: 20 настоящих названий и порядок станций из опубликованного расписания,
49,5 км суммарной длины. Геометрия карты, уклоны, платформы и скорости иллюстративные;
это промежуточная демка, не точная реконструкция инфраструктуры или кабины.

- W/S — контроллер, Q/E — кран №395, R — реверсор, Backspace — экстренное торможение.
- Space — тифон, V — свисток. Держать клавишу; отпускание плавно затухает 0,65/0,50 с.
- Z/C — левые/правые двери: открываются на остановке, открытые двери блокируют тягу.
- F8 — вернуть ракурс со стороны платформы.
- F2 — виды спереди, сзади, сбоку, из кабины, проекция 2.5D.
- ПКМ + движение мыши — вращение; Control + левая кнопка — альтернатива на Mac.
- Shift + ПКМ или средняя кнопка — сдвиг; жест двумя пальцами — поворот, щипок — масштаб.
- Колесо или +/− — масштаб; [/] — поворот, PageUp/PageDown — наклон, F — вернуть камеру.
- F3 — настройки камеры, подвески, ночного света, звука, разрешения окна и масштаба рендера.
  Окно по умолчанию развёрнуто; ручной размер и режим сохраняются.
  100% рендера соответствует физическому изображению окна, включая HiDPI; до 200% — суперсэмплинг.
  MSAA: выключено / 2× (по умолчанию) / 4×. Мелкие колёса получают автоматический LOD; вблизи полный профиль.
  По умолчанию камера сохраняет выбранный угол; слежение за направлением включается отдельно.
- F4 — полный пульт, F5 — полная карта, F1 — панели, F10 — сброс их расположения.
- I или кнопка «Інформатор» на пульте — повторить объявление, L — прожектор.
- P — пауза, Esc — главное меню. Ускорения времени нет.

Информатор работает без сети: 41 заранее синтезированная украинская фраза (Ukrainian TTS,
Tetiana), а не записи оператора с YouTube. Лицензированные оригинальные записи можно
подложить в user://announcements/ с теми же именами. Субтитры остаются при выключенном звуке.
Подробные источники и лицензии звуков находятся в game/audio/*/CREDITS.md и в сборке.

Качение — длинные звуковые петли из OpenSFX; стук — отдельные записанные импульсы. Пары осей пересекают стыки по своей геометрии. Четыре записанных импульса смешиваются
в PCM-потоке с точными временами, без короткой ритмической петли и повышения тона со скоростью.
Отдельный поток заполняет аудиобуфер даже при задержках рендера. Камера интерполирует
фиксированные шаги симуляции; небольшое регулируемое качание относится только к кузову,
колёса остаются на рельсах. Продольной тряски модели нет.

## Сборка из исходников

Подготовка звуков из исходников на Linux: `bash tools/prepare_demo_audio.sh` (OpenSFX + Kenney Interface Sounds +
Ukrainian TTS; это сборочная зависимость, пользователю EXE/DMG не нужна). WAV не хранятся
в Git: конвейер передаёт их между сборочными заданиями через artifacts.

Python 3.12+: `python tools/install_godot.py --templates` печатает путь проверенного Godot 4.7.2.
`python tools/build_desktop.py --godot <путь> --target windows --out build/release`
На macOS: аналогично `--target macos` — ZIP экспортируется и упаковывается штатным hdiutil.
`--target all` собирает обе платформы. Конвейер desktop-release.yml делает это на macOS,
проверяет подпись, запускает приложение без окна, а затем проверяет EXE на Windows и
выкладывает файлы в GitHub Releases с SHA256SUMS.txt. Сейчас Actions заблокирован биллингом
аккаунта; опубликованные выше пакеты собраны локально в Linux и размещены в отдельной ветке
demo-downloads. Нативные проверки Windows/macOS ещё не выполнены.

Кузова поддерживаются двумя тележками, ориентированными по колёсной базе.
Положение сцепленных вагонов решается совместно; поддерживается постоянная база кузова
и длина сцепки с малым упругим откликом. Подвеска реагирует на ускорение с учётом массы,
платформы следуют кривой пути с постоянным зазором. Модель остаётся приближённой,
полный многотельный расчёт контакта колеса и рельса не заявляется.

В 0.3.3 исправлен расчёт длины петель: используются звуковые отсчёты, а не размер
сжатого WAV. Записи импортируются в PCM16, включая импульсы стука. Удержание тифона
и свистка проверено дольше трёх секунд, без короткого повторного запуска.

Уклон и сопротивление кривой теперь интегрируются по полной длине каждого вагона,
с учётом перехода через узлы и обратного направления. Детали жёстких частей объединены
для сокращения draw calls. Двери, колёсные пары и складывающийся токоприёмник сохраняют
собственную анимацию. Первый 3D-кадр скрыт до установки камеры.

Встречный путь и вторая наружная платформа — пока визуальная демонстрация; второй
маршрутизируемый путь и ИИ-движение не добавлены. Их компоновка не является проверенной
схемой реальных станций. Для точных 2–3 станций нужны доступные OSM/фото-источники.
Реверсор R и кнопки «Вперед / 0 / Назад» меняют направление на остановке.

Пользователь подтвердил нативный запуск 0.3.2 на Windows и macOS. Это отдельная ручная
проверка; автоматизированный hosted CI по-прежнему заблокирован биллингом GitHub.
