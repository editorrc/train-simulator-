# ARTEM · Train Emulator · демка 0.3.5

ARTEM — Artificial Realistic Train Emulator with Modifications.

Windows: распаковать ARTEM-Windows.zip и запустить ARTEM.exe. Движок устанавливать
не нужно. macOS: открыть ARTEM-macOS-universal.dmg, перенести ARTEM.app в «Программы».
В приложении Intel + Apple Silicon. Подпись ad-hoc; Developer ID/нотариализации нет.
Для первого запуска при блокировке: «Конфиденциальность и безопасность → Всё равно
открыть» для этого приложения; отключать защиту macOS не требуется.

Меню «Панорама»: Огляд / Рейс / Поїзд / Налаштування / Керування. Выбор серии
(ЕР9М, ЕД9М, ЕПЛ9Т, ЕКр1 «Тарпан»), состава (4/6/8/10; у ЕКр1 3/6) и одной из
шести окрасок серии, готовый поезд либо холодный запуск на полигоне. Параметры
новых серий — оценки, ещё не сверенные с документацией.
«Почати поїздку →» начинает выбранную поездку. Подсказки/переназначение — в «Керування».

- ↑/↓ — следующая/предыдущая позиция контроллера. ←/→ — кран к отпуску/торможению.
- R / Shift+R / Option+R — реверсор уперёд / нейтраль / назад (на Windows Alt+R).
- ⌫ (Backspace) — экстренное торможение.
- Пробел — непрерывный тифон, V — свисток; отпускание оставляет плавный хвост.
- Z/C — левая/правая сторона дверей; открытые двери блокируют тягу.
- Tab — следующий вид; F (буква) — со стороны платформы; D — пульт, M — карта.
- Esc — меню паузы с продолжением; P — пауза. Выход из рейса — отдельной кнопкой.
- ⌘+, — настройки, ⌘+/ — управление; на Windows/Linux Ctrl вместо Command.
- ПКМ либо Control+клик — вращение; Shift+ПКМ — сдвиг; колесо — масштаб.
- Тачпад: прокрутка — огляд, щипок — масштаб. Все основные действия без F-ряда.
- Панели перетаскиваются за заголовок, изменяют размер и сворачиваются.

Клавиши физические: украинская/русская раскладка не меняет их расположение.
Переназначение с проверкой конфликтов сохраняется локально. При паузе/диалоге/
потере фокуса удержания освобождаются; ввод в настройках не управляет поездом.

Питание: B — АКБ, N — цепи управления, Y удерживать — дополнительный компрессор,
U — пантограф, G/H — включить/выключить ГВ, A — вспомогательные машины,
K — компрессоры, J — ЭПГ, L — прожектор, X — сброс защиты, I — информатор.
Все органы также доступны мышью. Процедура и пульт приближённые, не заводская копия.

Звук: OpenSFX/Kenney, 41 синтезированная украинская фраза Tetiana; лицензии в пакете.
Это не натурный комплект звуков ЕР9М. Геометрия кольца, уклоны, скорости и платформы
иллюстративные; настоящие 20 названий/порядок из опубликованного расписания.
Вывески у платформ объёмные. Второй путь визуальный, без маршрутизации/ИИ.
Новые фото-палитры приблизительные; три исходные схемы художественные.
