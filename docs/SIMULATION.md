# Модели симуляции

> Все числовые коэффициенты ниже — **стартовые / справочные** и требуют сверки с источниками
> (см. [RESEARCH.md](RESEARCH.md)). В коде они не хардкодятся, а живут в JSON состава с пометкой `verified`.
> Внутри ядра — СИ; в формулах ниже традиционные ж/д единицы указаны явно.

## 1. Динамика поезда (продольное движение)

Основное уравнение (точечная масса, MVP):

```
m · (1 + γ) · dv/dt = F_тяги − W_осн − W_укл − W_кр − B_торм
```

| Символ | Смысл | Комментарий |
|---|---|---|
| `m` | масса состава, кг | тара + пассажиры (загрузка задаётся сценарием) |
| `γ` | коэффициент инерции вращающихся масс | для МВПС порядка 0.08–0.12, уточнить |
| `F_тяги` | сила тяги на ободе колёс, Н | из тяговой характеристики и ограничения по сцеплению |
| `W_осн` | основное сопротивление движению | `w0 = a + b·v + c·v²` (Н/кН, v в км/ч), коэффициенты — по Правилам тяговых расчётов (ПТР) для МВПС |
| `W_укл` | сопротивление от уклона | `w_i = i` (Н/кН, i в ‰; подъём +, спуск −), с учётом распределения состава по профилю |
| `W_кр` | сопротивление от кривой | `w_r = 700 / R` (Н/кН, R в м) — классическая формула ПТР, на длине состава в кривой |
| `B_торм` | тормозная сила, Н | пневматика/ЭПТ + электрическое торможение (если есть у серии) |

Сопротивление при трогании с места — отдельная добавка (по ПТР), убывающая до ~0 к нескольким км/ч.

### Интегрирование
- Полунеявный Эйлер на `SIM_DT = 1/60 с` достаточен. Скорость не может стать отрицательной
  при торможении (зажать в 0, если нет силы, тянущей назад — например, скатывание на уклоне без тормозов **возможно** и должно моделироваться).
- Проверочные тесты: разгон на площадке, выбег, тормозной путь со 100 км/ч, скатывание на спуске.

## 2. Сцепление (адгезия) и боксование/юз

- Предельная сила тяги: `F_max = ψ_к(v) · P_сц · g`, где `P_сц` — сцепной вес моторных осей.
- `ψ_к(v)` — расчётный коэффициент сцепления, формула вида `ψ = A + B / (C + D·v)` (коэффициенты по ПТР для МВПС — уточнить).
- Модификаторы: мокрые/обледенелые рельсы (погода), листопад, подсыпка песка (если есть у серии).
- Превышение → **боксование** (тяга падает, звук, индикация, нарушение при длительном) / при торможении → **юз**.

## 3. Тяговый электропривод (Киевский узел — переменный ток 25 кВ 50 Гц)

> Серии ЕР9М, ЕД9М, ЕПЛ9Т — электропоезда **переменного тока**. Уточнить схемы по руководствам по эксплуатации.

Цепочка: **токоприёмник → главный выключатель (ГВ) → тяговый трансформатор → выпрямитель →
регулирование (ступени / групповой переключатель) → тяговые двигатели (ТЭД)**.

Моделируемые состояния и условия:
- Напряжение в КС (номинал 25 кВ; колебания, нейтральные вставки — **вставки обязательно моделировать**:
  отключение ГВ / сброс тяги перед вставкой, иначе нарушение).
- Токоприёмник: опущен / поднимается / поднят; требует давления воздуха в цепях управления.
- ГВ: выключен / включён / отключён защитой (перегрузка, КЗ, нулевое напряжение) → требуется повторное включение по процедуре.
- Контроллер машиниста: позиции хода (например `0, М, 1, 2, 3, 4` — уточнить по серии) и тормозные (если есть).
  Позиция задаёт **целевую ступень**, переходы между ступенями — с задержкой автоматики (не мгновенно).
- ТЭД: ток якоря ограничен защитой; тяга = f(ступень, скорость) — **табличная тяговая характеристика** в JSON с интерполяцией.
- Вспомогательные цепи: расщепитель фаз / статический преобразователь (уточнить по серии), компрессоры, вентиляторы, освещение, АКБ 50 В (уточнить).

## 4. Пневматика и тормоза

### 4.1 Резервуары и магистрали
| Элемент | Назначение | Типичный диапазон (уточнить для МВПС) |
|---|---|---|
| ГР — главные резервуары | запас сжатого воздуха | регулятор давления компрессора, порядка 6.5–8.0 кгс/см² |
| ТМ — тормозная магистраль | управление воздухораспределителями | зарядное давление для электропоездов ~4.5–4.8 кгс/см² |
| ЗР — запасные резервуары | питание ТЦ на вагонах | заряжаются от ТМ |
| ТЦ — тормозные цилиндры | создают нажатие колодок | максимум зависит от режима |

Модель: каждый объём — `p, V`; потоки через «отверстия» `Q = k · sign(Δp) · sqrt(|Δp|)` (достаточно для игры);
задержка распространения волны по ТМ вдоль состава (для МВПС мала, но параметр нужен для локомотивной тяги).

### 4.2 Кран машиниста (усл. № 395 или аналог по серии — уточнить)
Положения: **I** — отпуск и зарядка; **II** — поездное; **III** — перекрыша без питания;
**IV** — перекрыша с питанием; **V** — служебное торможение; **Vа** — служебное с замедленной разрядкой;
**VI** — экстренное. Для ЭПТ — электрические положения торможения/перекрыши в тех же положениях ручки.

### 4.3 ЭПТ (электропневматический тормоз)
Основной служебный тормоз МВПС: мгновенное наполнение ТЦ по всему составу; пневматика — резерв.
Неисправность ЭПТ (сценарий) → переход на пневматическое управление.

### 4.4 Тормозная сила
`B = Σ φ_к · K_колодки`, где коэффициент трения колодки `φ_к(v, K)` — по эмпирической формуле ПТР для чугунных/композиционных колодок (тип колодок — в данных).

### 4.5 Проба тормозов
Полная/сокращённая проба по правилам: снижение давления в ТМ на заданную ступень, контроль срабатывания и отпуска, контроль плотности ТМ. Это **игровой шаг процедуры** приёмки (M3) и проверяется сценарием.

## 5. Системы безопасности

### 5.1 АЛСН (автоматическая локомотивная сигнализация непрерывного действия)
- Получает кодовые сигналы от рельсовых цепей автоблокировки (числовой код: «З», «Ж», «КЖ»).
- Локомотивный светофор: **З, Ж, КЖ, К, Б** (белый — нет кодов / некодируемый участок).
- Логика смены показаний — от состояния блок-участков впереди (см. §6).

### 5.2 Бдительность: ЕПК + рукоятка бдительности (РБ)
- При смене на более запрещающее показание и периодически при КЖ/К — требование подтверждения РБ;
  свисток ЕПК → окно реакции (~7 с, уточнить) → иначе **автостоп** (экстренное торможение).
- Нарушения: автостоп, проезд сигнала с КЖ без нажатия, отключение ЕПК без причины.

### 5.3 Скоростной контроль
- Контроль допустимой скорости на показании (например, на Ж / КЖ — ограничения по ПТЕ/инструкциям),
  постоянные ограничения пути и временные «предупреждения».
- Более современные устройства (КЛУБ-У, САУТ и т.п.) — **позже**, если реально стоят на выбранных сериях.

## 6. Сигнализация и путевое развитие

### 6.1 Светофоры (по Інструкції з сигналізації на залізницях України — уточнить формулировки)
Типы: входной, выходной, маршрутный, проходной (автоблокировка), маневровый, предупредительный, повторительный, заградительный.
Базовые показания для MVP:

| Показание | Смысл (упрощённо, для MVP) |
|---|---|
| 🟢 зелёный | свободны два и более блок-участка |
| 🟡 жёлтый | следующий сигнал закрыт, готовиться к остановке |
| 🟡🟡 два жёлтых (верхний мигающий / немигающий) | следование на боковой путь по стрелочному переводу, с ограничением скорости |
| 🔴 красный | стой, проезд запрещён |
| ⚪ лунно-белый мигающий | пригласительный — проезд с особой осторожностью ≤ 20 км/ч |
| 🔵 синий | (маневровый) маневры запрещены |

Точный список показаний и скоростей — **из нормативного документа**, таблица лежит в данных (`signal_aspects.json`), а не в коде.

### 6.2 Автоблокировка
- Трёхзначная (MVP) → четырёхзначная (позже).
- Перегон делится на блок-участки; поезд занимает участок по осям (рельсовая цепь) → сигнал позади = красный, следующий = жёлтый и т.д.
- Генератор кодов АЛСН по состоянию блок-участков.

### 6.3 Станционная централизация (упрощённо)
- Маршрут = набор стрелок + сигнал начала. ДСП (ИИ или игрок в будущем) задаёт маршрут, ядро проверяет
  враждебность маршрутов, замыкает стрелки, открывает сигнал.
- Ручное разрешение / пригласительный сигнал / письменные разрешения (бланки) — сценарные ситуации.

## 7. Правила ПТЕ как игровая логика

Правило = объект `Rule { id, source_ref, check(world) -> Violation? , severity }`.
`source_ref` — ссылка на пункт документа (например `ПТЕ п. X.Y`, заполняется по RESEARCH.md).

Минимальный набор для MVP:
1. Проезд запрещающего сигнала (SPAD) — критическое, конец рейса.
2. Превышение установленной скорости (постоянное / временное / по показанию сигнала / АЛСН).
3. Отправление без разрешения ДСП / без открытого выходного сигнала.
4. Отправление с открытыми дверями; открытие дверей не с той стороны / вне платформы.
5. Остановка не у платформы / проезд остановочного пункта по расписанию.
6. Не выполненная проба тормозов перед отправлением.
7. Автостоп ЕПК (не подтверждена бдительность).
8. Проход нейтральной вставки под током.
9. Нарушение регламента переговоров (пропущенная/неверная реплика).
10. Экстренное торможение без необходимости, резкие рывки (комфорт пассажиров — штраф, не нарушение).

## 8. Переговоры (регламент)

- Диалоговое дерево в данных (`radio/*.json`): кто инициирует, обязательные элементы фразы
  (позывной, номер поезда, путь, показание сигнала), правильный ответ, тайм-ауты.
- Примеры ситуаций MVP: доклад о готовности к отправлению, получение разрешения на отправление,
  повторение показаний сигналов в кабине («Зелёный!» — «Бачу зелений!»), доклад о проследовании,
  сообщение о неисправности, «Внимание всем!» при остановке на перегоне.
- **Тексты фраз брать из официального регламента**, не сочинять. Пока источник не найден — заглушки с пометкой `TODO_SOURCE`.
