  Удержания по фронтам, OS echo игнорируется; модификатор можно отпустить первым.
- Пауза без уничтожения рейса, видимые кнопки; диалоги блокируют команды поезда.
- Названия станций на объёмных двухсторонних щитах, без billboard.
- Предпросмотр: off-axis frustum, студийный свет/отражения, рельсы. Нос/крыша,

## Важно: дизайн ещё не принят как точное совпадение

Пользователь несколько раз отклонил кадры: поезд слишком мелкий/боковой,
рейс слишком широкий, фон только отдельной подложкой у поезда, неверная иерархия
названия. Последние исправления устраняют это, но **реализм модели всё ещё
уступает эталонному арту**. Не объявлять меню «точно как макет» без сравнения
свежего нативного кадра с C. Приоритет — закончить эту композицию/модель,
затем 2–3 дополнительные серии по ROADMAP R0. Не заменять поезд статичным
скриншотом макета и не терять фактическое количество/окраску.

Не потерять прежние приоритеты: непрерывные гудок/свисток и их хвосты, физика
без рывков, оптимизация/HiDPI/развёрнутое окно, не показывать стартовую камеру
с путей, реальные стороны платформ 2–3 станций, встречный путь и оборот.
Геометрия сейчас иллюстративная, второй путь не маршрутизируется, модель не
заводская, ТТХ verified:false. Не маскировать эти ограничения статусом «готово».

## Среда и команды

```bash
cd /workspace/train-simulator-
source /workspace/.train-simulator/env.sh
python tools/prepare_fonts.py
python tools/check_audio_assets.py
make check
```

Godot 4.7.2 и шаблоны в /workspace/.local. Аудио 59 PCM16 файлов уже получено,
игнорируется и включается в сборки. Если отсутствует: tools/prepare_demo_audio.sh.
Сеть после публикации работает: Wikipedia/Commons API HTTP 200; Overpass HTTP 406.
Сырые ответы/референсы в build/research. Часть официальных HTTP 200 — служебные
страницы, не подтверждённые документы (ПТЕ). Исследования различают это.

GUI: Xorg :99, конфигурация /workspace/.train-simulator/xorg.conf;
оконный менеджер `DISPLAY=:99 dbus-run-session -- xfwm4 --compositor=off`.
Живые процессы не переживают публикацию среды, при необходимости пересоздать.

```bash
DISPLAY=:99 godot --path game --audio-driver Dummy -s res://tests/visual/navigation_regression.gd
DISPLAY=:99 godot --path game --audio-driver Dummy -s res://tests/visual/capture_panorama.gd
DISPLAY=:99 godot --path game --audio-driver Dummy -s res://tests/visual/performance_regression.gd -- --msaa2
```

Профиль производительности запускать отдельно от других Godot/тестов.
Ранее навигация/переназначения/пауза прошли native Godot GUI в Linux; 105 headless
тестов и parity 801 прошли. Для последних графитовых кадров см. BUILD_VALIDATION.
Принудительный выход некоторых QA-сцен оставляет ObjectDB/resources warnings,
не выдавать это за чистое завершение. Hosted CI заблокирован биллингом.

## Сборки и доставка

Пакетирование теперь ARTEM-Windows.zip / ARTEM-macOS-universal.dmg / ARTEM.app.
tools/build_desktop.py загружает шрифты, tools/verify_desktop.py проверяет форматы.
Для Linux DMG:

```bash
python tools/build_desktop.py --godot "$GODOT" --target all --out build/release-v034 \
  --xorriso /workspace/.local/tools/dmg-packages/root/usr/bin/xorriso \
  --xorriso-library-dir /workspace/.local/tools/dmg-packages/root/usr/lib/x86_64-linux-gnu \
  --dmg-tool /workspace/.cache/train-assets/libdmg-hfsplus/build/dmg/dmg
python tools/verify_desktop.py build/release-v034 --hfs-out /tmp/artem-v034.hfs
```

Не путать пакетирование с нативной приёмкой. Пользователь подтвердил запуск
**0.3.2** на обеих ОС. Mac — ad-hoc, без Developer ID/нотариализации.

## Последний измеренный профиль (нужна оптимизация)

10 вагонов, 1280×800 физического рендера, MSAA2, Xorg/llvmpipe: 620,15 draw calls,
165177 примитивов, 3102 узла, средний кадр 184,91 мс. Это программный рендер
текущего хоста, не FPS на Mac. С предыдущим отчётом 0.3.3 напрямую не сравнивать
без повторного запуска базы на том же хосте. Проверить стоимость двухстороннего
RigidMeshBatch (cull_disabled), новой геометрии и вывесок; уменьшить затраты,
сохранив корректные видимые грани. Принудительный выход сохранил 10 ObjectDB и
4 resource warnings. Не объявлять оптимизацию/освобождение завершёнными.

Последняя правка предпросмотра: весь состав стоит на прямом выставочном пути,
независимом от кривой игрового маршрута. Камера обязана показывать последний
вагон при 4/6/8/10; это проверяется в navigation_regression.gd.
