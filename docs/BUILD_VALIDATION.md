# Проверка промежуточной демки 0.3.1 — 2026-10-17

Исходники приложения: ce6ab07dfbb2e69a60f42ad63e7d3a173e42edc2, тег demo-v0.3.1.
Пакеты: отдельная ветка demo-downloads, неизменяемый коммит
[d8a543ae6adad0a352619c546fdb3328dab309e0](https://github.com/editorrc/train-simulator-/tree/d8a543ae6adad0a352619c546fdb3328dab309e0).

Проверено в облачной Linux-среде с официальным Godot 4.7.2 (SHA512 официальных архивов):

- make check: 83 Godot-теста, 2 Python-теста, 18 файлов данных без ошибок,
  форматирование/линт, 801 образец JS/GDScript parity, свежесть веб-превью.
- Настоящий рендер OpenGL/llvmpipe: меню, формация, виды спереди/сзади/из кабины,
  проекция 2.5D, ночь, полный пульт, карта и настройки. Удержание и отпускание мышью
  свистка, кнопка информатора, загрузка офлайн-фразы. Ошибка дальних табличек 2.5D
  исправлена отсечением платформ вне видимого диапазона; повторный проход без ошибок рендера.
- Звук: запись 6,41 с при искусственных задержках кадров 55/120 мс; пустых блоков 100 мс
  нет, пик PCM 0,4984, клиппинга нет. Проверены хвосты обоих сигналов и повторное нажатие.
  Это цифровая проверка в Linux, не прослушивание на целевых устройствах.
- Самостоятельный Linux-экспорт запускает меню из встроенного PCK.
- Windows: PE x86_64 со встроенным PCK, EXE внутри ZIP совпадает с экспортом побайтно.
- macOS: universal Mach-O x86_64 + arm64, ad-hoc CodeDirectory в обеих архитектурах,
  CodeResources и PCK присутствуют. Контрольные суммы таблиц UDIF и обратная распаковка
  HFS+ совпадают с исходным томом; извлечённый из DMG исполняемый файл имеет тот же SHA256.
- Повторное скачивание Windows ZIP и DMG по опубликованным HTTPS URL: HTTP 200,
  SHA256 совпадает. Внутренние пути облачной машины для выдачи не используются.
