# Проверка промежуточной демки 0.3.2 — 2026-10-17

Исходники приложения: тег demo-v0.3.2.
Пакеты: отдельная ветка demo-downloads, неизменяемый коммит
[b4bd9e6694c420fbcb4f3d6aeb7b338f943cf3a3](https://github.com/editorrc/train-simulator-/tree/b4bd9e6694c420fbcb4f3d6aeb7b338f943cf3a3).

Проверено в облачной Linux-среде с официальным Godot 4.7.2 (SHA512 официальных архивов):

- make check: 90 Godot-тестов, 2 Python-теста, 18 файлов данных без ошибок,
  форматирование/линт, 801 образец JS/GDScript parity, свежесть веб-превью.
- Новые проверки: постоянная база кузова и расстояние сцепки на кривых, ориентация
  тележек по осям, отклик подвески на ускорение, стыковые события для каждой оси,
  обратный ход и границы PCM-блоков без потери событий.
- Настоящий рендер OpenGL/llvmpipe: меню, состав, виды спереди/сзади/из кабины,
  проекция 2.5D, ночь, полный пульт, карта и настройки; платформы следуют дуге пути.
- Автоматизированная проверка камеры: ПКМ, Control + ЛКМ с отпусканием Control раньше
  кнопки мыши, жест тачпада, свободный взгляд из кабины, выбор задней кабины при реверсе.
  Прожектор сохраняет направление состава при повороте взгляда. Размер рендера 100%
  совпал с framebuffer 1334 × 834, при 150% — 2001 × 1251. Это размеры Linux-теста,
  не замер на дисплее Mac.
- Звук: 59 корректных PCM16-ресурсов. Отдельный поток стука не увеличил счётчик
  опустошений буфера (0 → 0) при искусственных задержках главного потока до 350 мс.
  Проверены затухания тифона/свистка, повторное нажатие и офлайн-фраза информатора.
  Это цифровая проверка в Linux, не прослушивание на целевых устройствах.
- Расчёт поз 10 вагонов: в среднем 2,046 мс на 100 вызовах возле Киев-Пассажирского
  на CPU облачной Linux-машины. Это время одного расчёта, не FPS и не замер на Mac.
- Windows: GUI PE x86_64 со встроенным PCK, 111497136 байт; EXE внутри ZIP
  совпадает с экспортом побайтно.
- macOS: universal Mach-O x86_64 + arm64, ad-hoc CodeDirectory в обеих архитектурах,
  CodeResources и PCK присутствуют. Проверены CRC и таблицы UDIF; обратная распаковка
  HFS+ совпадает с исходным томом побайтно. Извлечённый из DMG исполняемый файл совпадает
  с приложением: SHA256 5a2fe92cabe10320bc7297d96a10956e2eb73d3fddd5874445f856861a67f220.
- Повторное скачивание Windows ZIP и DMG по опубликованным HTTPS URL: HTTP 200,
  SHA256 совпадает. Внутренние пути облачной машины для выдачи не используются.

Запуск на Windows/macOS и штатные codesign/hdiutil-проверки на Mac пока не выполнены.
[GitHub Actions run](https://github.com/editorrc/train-simulator-/actions/runs/39034694815)
не начал задания: “The job was not started because your account is locked due to a billing issue.”
Это внешняя блокировка, не успешная проверка. Конвейер сохранён для повторного запуска
после восстановления Actions. Аудио воспроизводимо генерируется без Git LFS: прямая
отправка WAV в LFS ранее была отклонена из-за исчерпанной квоты.

При принудительном завершении Linux QA-сцен остаётся предупреждение ObjectDB и 5 ресурсов
при выходе; чистое освобождение памяти при закрытии не заявляется. Кузов опирается на
две тележки, сцепки сохраняют расстояние, подвеска имеет инерционный отклик. Это направляемая
кинематика и визуальная подвеска, а не полный многотельный расчёт контакта колеса и рельса.
Модели/геометрия иллюстративные, голос синтезированный.
