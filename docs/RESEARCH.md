# План исследования (research backlog)

Цель: собрать данные, без которых «реалистично» превращается в «на глаз».
Правило: **каждый найденный факт → в JSON-данные с источником** (`meta.sources`), а сюда — отметка ✅.

Приоритеты: **P0** — нужно для MVP (вехи M1–M5), **P1** — для M6–M8, **P2** — потом.
